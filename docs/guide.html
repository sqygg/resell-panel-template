1. What This Does

┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  Your SellAuth   │────▶│  Reseller Panel   │────▶│  Reseller A      │
│  Shop (products) │     │  (this project)   │     │  (gets 25% off)  │
│                  │     │                   │────▶│  Reseller B      │
│  price: $10.00   │     │  applies discount │     │  (gets 15% off)  │
│  stock: 50       │     │  per reseller     │────▶│  Reseller C      │
└─────────────────┘     └──────────────────┘     │  (gets 0% off)   │
                                                  └─────────────────┘

What it does:

  • Pulls your product catalog + stock from your SellAuth shop automatically.
  • Each reseller gets a unique API key.
  • Each reseller has a custom discount percentage you set.
  • Resellers query your panel and see products at their discounted prices.
  • Resellers NEVER see your SellAuth directly — they only talk to your panel.
  • Resellers get a storefront (web dashboard) to browse, order, and track history.
  • Prepaid balance system — resellers deposit funds, orders deduct automatically.
  • Referral system — resellers refer others and earn a % commission.
  • Public application form — new resellers apply, you approve/reject from the admin panel.
  • Security hardening — hashed API keys, rate limiting, audit logs.

3. Get Your SellAuth Credentials

You need two values from your SellAuth dashboard.

3.1 — Get your API Key

  1. Go to https://dash.sellauth.com and log in.
  2. In the left sidebar, click Account → Developers (or API).
  3. Copy your API key — it looks like sa_live_xxxxxxxxxxxxxxxx.
Save this key immediately. You may not be able to see it again. Never share it or put it in a client app — it stays server-side only.

3.2 — Get your Shop ID

  1. Click Shops in the sidebar, then click your shop.
  2. Look at the URL: https://dash.sellauth.com/shops/12345 — the number is your Shop ID.

7. Access the Admin Panel

Open http://YOUR_SERVER_IP:8000 and log in with your ADMIN_PASSWORD.

The admin dashboard shows:

  • Active Resellers — how many you have.
  • Total Products — pulled from SellAuth.
  • Total Stock — sum of all stock.

Top navigation: Dashboard / Resellers / Stock / Orders / Applications.

8. Add Your First Reseller

  1. Click Resellers → + Add Reseller.
  2. Enter name and discount %.
  3. Click Create — a popup shows the API key once.
Copy the API key now. It is shown only once. You can regenerate it (invalidates the old one) but can never view it again — keys are stored hashed.

How discount works: product costs $40 retail, reseller discount 25% → reseller sees $30. The original_price is also shown so they know the retail.

9. Onboard a Reseller

Give a new reseller three things:

📡 Storefront:  http://YOUR_SERVER_IP:8000/store/login
🔑 Your Key:    rs_xxxxxxxxxxxxxxxx
💰 Discount:    25% off all products

They can log into the storefront with their API key, OR use the raw API (below).

10. How Resellers Use the API

Resellers only need one URL. The API key goes in the path.

# Health check (verify the key works)
GET /api/webhook/{api_key}/health

# Get all products with their discounted prices
GET /api/webhook/{api_key}

Response includes price (discounted) and original_price (retail).

Query paramExampleDescription
page?page=2Page number (default 1)
per_page?per_page=100Products per page (max 200)
type?type=serviceFilter by service or file

11. The Reseller Storefront

Resellers get a full web dashboard at /store. After logging in with their API key, they see:

  • Dashboard — "Welcome back" summary: balance, discount, total orders, referral earnings, recent orders.
  • Products — browse the catalog at their discounted prices, place orders.
  • Orders — full order history.
  • Balance — current balance + transaction history.
  • Referrals — their referral code, link, and earnings.

Orders deduct from the reseller's prepaid balance. When a reseller places an order, the panel creates a SellAuth checkout link they can send to their customer — SellAuth auto-delivers after payment.

12. Referral System

Every reseller automatically gets a unique referral code (e.g. XK4F9T2Q).

  • Resellers share their link: http://YOUR_SERVER_IP:8000/store/apply?ref=XK4F9T2Q
  • When a new reseller applies with that code and is approved, they're linked.
  • The referrer earns REFERRAL_COMMISSION_PERCENT (default 5%) of every order the referred reseller places.
  • Commission is credited automatically to the referrer's balance.

13. Reseller Applications

The public form at /store/apply collects: email, Discord, website, Discord server, products, and optional referral code.

In the admin panel, Applications shows all pending applications:

  • Approve → enter a name + discount % → creates the reseller automatically (and links any referral).
  • Reject → marks it rejected.
The default discount for approved applications is DEFAULT_APPLICATION_DISCOUNT (default 30%).

14. Day-to-Day Operations

  • Add balance to a reseller — Resellers → Edit → "Add Funds".
  • Change a discount — Resellers → Edit → Discount %.
  • Suspend a reseller — Resellers → Edit → Status = Inactive.
  • Rotate a key — Resellers → 🔄 (old key stops working immediately).
  • View all orders — Orders tab shows every reseller's orders.
  • Check stock — Stock tab reflects live SellAuth inventory.

15. Security Features

FeatureWhat it does
Hashed API keysKeys stored as SHA-256 hashes — a DB leak never reveals keys
Rate limiting60 req/min global, 30/min webhook, 5/min login per IP
Brute-force lockoutAdmin login locks after 5 failures / 15 min
Security headersCSP, X-Frame-Options, nosniff, etc.
Request size limitRejects bodies over 64 KB
Audit logEvery admin action is logged with IP
Constant-time comparePassword/key checks use hmac.compare_digest

17. Troubleshooting

ProblemFix
"No products loaded"Check SELLAUTH_API_KEY / SELLAUTH_SHOP_ID in .env. Test with curl (step 3).
SellAuth returns 401Your API key is stale/revoked — regenerate in dash.sellauth.com.
Can't log into adminToo many attempts → wait 15 min. Or check ADMIN_PASSWORD.
Port 8000 in useChange PORT in .env or remap in docker-compose.yml.
Reseller can't log into storeVerify they're using the full API key (starts with rs_).
Discord bot not connectingDISCORD_BOT_TOKEN empty → bot disabled (expected). Add token to enable.
