Frequently Asked Questions

What is SkriptX Panel?+
SkriptX Panel is an all-in-one reselling platform for gaming solutions (such as R6 linker keys). It gives resellers a branded dashboard to manage balance, buy keys at custom discounts, and pull real serials straight from our SellAuth stock via a signed API — with automated webhook delivery and 24/7 support.
How do I become a reseller?+
Apply at /apply. We review every application (Discord + a website/social are required) and approve manually. Once accepted you get a dashboard login and an API key, plus a per-reseller discount % applied automatically on every order.
How are keys delivered?+
Instantly. When a reseller buys or pulls a key, SkriptX Panel delivers a real serial from live SellAuth stock and fires a webhook to your endpoint. No manual copy-paste, no waiting — delivery is automated and logged.
What discounts do resellers get?+
Each reseller has a custom discount percentage set by the owner. It's applied automatically at checkout, so your price is always correct without coupon codes. Higher-volume resellers can request a better rate through their dashboard.
Is my account and API key secure?+
Yes. Secrets are hashed (never stored in plaintext), API keys are shown only once at generation, every endpoint is rate-limited, and all sensitive actions are audit-logged. Treat your API key like a password — if it leaks, regenerate it instantly from Settings and the old key dies immediately.
