Reseller API

Authenticate with your reseller password (issued by the owner). All responses are JSON.

GET List products (discount applied)

GET /api/webhook/{API_KEY}?page=1&per_page=50

Returns your catalog with your discount already applied to every price.

GET Single product

GET /api/webhook/{API_KEY}/product/{PRODUCT_ID}

POST Deliver keys (API delivery)

POST /api/deliver/{API_KEY}
Content-Type: application/json

{
  "product_id": "123",
  "variant_id": "456",      // optional — first variant used if omitted
  "quantity": 1,            // 1–50
  "customer_email": "buyer@x.com",
  "order_id": "your-ref-001" // optional, your own reference
}
Dispenses real keys/serials from the owner's SellAuth stock and returns them in keys[]. If you configured a webhook URL, the keys are also POSTed to it as JSON {event:"delivery", keys:[...], ...}. The order is recorded and referral commission credited automatically.

Example (curl)

curl -X POST https://YOUR-PANEL.com/api/deliver/rs_YOURKEY \
  -H "Content-Type: application/json" \
  -d '{"product_id":"123","quantity":1}'

Example response

{
  "success": true,
  "order_id": 42,
  "product_id": "123",
  "variant_id": "456",
  "quantity": 1,
  "keys": ["KEY-AAAA-1111-XXXX"],
  "webhook_status": 200
}

Need a key? Ask the owner or apply at /apply.
